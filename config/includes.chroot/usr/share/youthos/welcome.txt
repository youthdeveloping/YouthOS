YouthOS에 오신 것을 환영합니다!
=================================

YouthOS는 청소년 개발자가 배우고, 만들고, 공유할 수 있도록 만든 Debian 기반 운영체제입니다.

처음 시작하기
-------------

1. 바탕화면의 '내 홈 폴더'에서 개인 파일을 관리하세요.
2. '문서', '다운로드', '프로젝트' 아이콘을 눌러 각 폴더를 여세요.
3. '배경화면 설정'을 눌러 원하는 배경을 선택하세요.
4. '프로젝트' 폴더의 hello-python과 hello-web 예제를 실행해 보세요.

개발 도구
---------

- Thonny: Python 입문용 편집기
- Firefox: 웹 브라우저
- 터미널: 명령어 실행
- Git: 소스 코드 버전 관리

터미널 첫 명령어
----------------

Python 예제 실행:
  cd ~/Projects/hello-python
  python3 main.py

웹 예제 폴더 열기:
  thunar ~/Projects/hello-web

중요한 안내
-----------

GitHub와 Cloudflare 계정은 각 사용자가 직접 로그인하세요.
비밀번호, API 토큰, 복구 코드는 다른 사람과 공유하지 마세요.

YouthOS 팀은 이 운영체제를 계속 개선하고 있습니다.
