# YouthOS 데스크톱 사용 안내

- by ChatGPT AI

## 기본 작업
- 홈, 문서, 다운로드, 프로젝트 바로가기로 개인 파일을 열 수 있다.
- 파일 관리자는 Thunar이며 USB 저장장치는 GVFS/UDisks를 통해 표시된다.
- 환영 화면은 첫 로그인 시 열리며, 설정 파일로 완료 여부를 기록한다.

## 시스템 설정
- 바탕화면의 YouthOS 설정 센터에서 화면, 네트워크, 소리, 블루투스, 테마, 전원, 키보드 설정을 연다.
- YouthOS 앱 관리자는 Synaptic 패키지 관리자를 연다.
- 시스템 업데이트는 사용자가 확인한 뒤 관리자 인증을 거쳐 패키지를 업데이트한다.
- 화면 잠금은 XFCE 세션의 기본 잠금 도구를 호출한다.
- 시스템 정보는 배포판, 커널, 아키텍처, 메모리, 루트 디스크 정보를 표시한다.

## 네트워크 및 장치
NetworkManager가 네트워크 연결을 관리한다. 무선 네트워크가 보이지 않으면 기기별 펌웨어/드라이버가 필요할 수 있다.
Bluetooth는 Blueman, 오디오 장치는 PulseAudio/PipeWire 호환 제어 도구를 통해 관리한다.

## 계정 및 관리자 권한
일반 사용자 계정은 Debian/Calamares에서 설정한다. 관리자 작업은 PolicyKit 인증을 사용한다. 공유 PC에서는 관리자 비밀번호를 다른 사용자와 공유하지 않는다.

## 주의
- 업데이트 도중 전원을 끄지 않는다.
- 저장소 설정이나 시스템 패키지를 변경하기 전 중요한 파일을 백업한다.
- 실기기 테스트 전에는 이 문서를 하드웨어 호환성 보증으로 간주하지 않는다.
