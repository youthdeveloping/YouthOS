## 1. 소스 및 빌드

- [ ] GitHub Actions의 `Build YouthOS ISO`가 성공했는가?
- [ ] `youthos-iso` 아티팩트가 생성되었는가?
- [ ] ISO 파일 크기와 SHA256 체크섬을 기록했는가?
- [ ] ISO가 UEFI와 레거시 BIOS 중 프로젝트가 지원한다고 선언한 부팅 방식에서 시작되는가?

## 2. 라이브 데스크톱

- [ ] 로그인/세션 진입 후 XFCE 데스크톱이 표시되는가?
- [ ] 한글 글꼴과 한글 입력(fcitx5-hangul)이 동작하는가?
- [ ] 네트워크 연결과 Wi-Fi 목록이 표시되는가?
- [ ] 바탕화면의 홈·문서·다운로드·프로젝트 바로가기가 Thunar에서 열리는가?
- [ ] 배경화면 설정 바로가기가 XFCE 설정 창을 여는가?
- [ ] 환영 문서가 Mousepad에서 열리는가?
- [ ] Thonny, Firefox, 터미널, 텍스트 편집기가 실행되는가?
- [ ] 재부팅 후에도 기본 설정이 유지되는가?

## 3. 개발 환경

- [ ] `python3 --version`, `git --version`, `node --version`이 정상 출력되는가?
- [ ] `~/Projects/hello-python`의 예제 프로그램이 실행되는가?
- [ ] `~/Projects/hello-web/index.html`이 브라우저에서 열리는가?
- [ ] 사용자가 직접 입력한 GitHub/Cloudflare 계정으로만 로그인되는가?
- [ ] 이미지에 개인 토큰, 비밀번호, API 키가 포함되지 않았는가?

## 4. 설치

- [ ] 새 사용자 계정에서 기본 폴더와 바로가기가 생성되는가?
